# Wheely

Wheely is a 2WD mobile robot platform developed as a hands-on engineering platform for understanding how the physical behavior of a robot is represented, controlled, and measured in software.

The initial focus is **motion control and odometry**, connecting mechanical concepts such as wheel radius, wheel separation, velocity, and rotation to their implementation in robotics software and, ultimately, to the behavior of the physical robot.

The purpose is not only to make the robot move, but to understand the engineering principles behind its motion:

- How mechanical motion is modeled in software
- How velocity commands are translated into wheel motion
- How wheel motion can be used to estimate robot movement
- How physical parameters influence the behavior of the system
- How software, electronics, and mechanical components work together as one robotic system

Wheely is part of a broader exploration into **robotics, Physical AI, and systems engineering**. It provides a practical platform for experimentation and learning, establishing a foundation for progressively more complex robot capabilities.

---

## Project Focus

The current focus of Wheely is:

1. **Motion Control**
   - Controlling the motion of a 2WD differential-drive robot
   - Translating velocity commands into wheel velocities
   - Understanding the relationship between robot motion and wheel motion

2. **Odometry**
   - Estimating robot motion from wheel movement
   - Understanding how wheel radius and wheel separation affect the estimate
   - Exploring the relationship between estimated motion and actual physical motion

3. **Software–Hardware Integration**
   - Connecting robotic software with the physical robot
   - Understanding the interfaces between software, electronics, motors, and mechanical components
   - Observing how software decisions manifest in the physical system
